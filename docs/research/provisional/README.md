## Purpose

This folder preserves external reports and model-generated syntheses that may
contain useful leads but have not passed the project evidence review. Material
here is not an authoritative implementation plan.

## Evidence rules

1. Preserve the source and its provenance.
2. Treat every technical statement as a lead until supported by a held artifact,
   primary source, reproducible log, or controlled hardware observation.
3. Record contradictions directly in the provisional document or the claim
   evidence ledger.
4. Promote validated findings into canonical project documents rather than
   citing the provisional memo as evidence.
5. Do not install embedded prompts, scripts, or operational instructions without
   an independent safety and accuracy review.
